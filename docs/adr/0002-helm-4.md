# ADR 0002 — Use Helm 4 instead of Helm 3

- **Status:** Accepted
- **Date:** 2026-10-30

## Context
The original plan named Helm 3. Homebrew now installs Helm 4 by default (4.3.1 installed). Helm 3 is at the end of its
announced support window (security fixes end in November 2026), so starting a new project on it would mean an early migration.

## Decision
Use **Helm 4** for all charts and local installs. Charts use `apiVersion: v2`, which works in both Helm 3 and Helm 4.

## Alternatives considered
| Option | Why not chosen |
|---|---|
| Stay on Helm 3 (`brew install helm@3`) | Matches older tutorials, but it is about to stop receiving security fixes. |

## Consequences
- Most tutorial commands (`helm upgrade --install`, `helm template`, `helm lint`) work unchanged.
- A few flags were renamed in Helm 4 (e.g. `--atomic` → `--rollback-on-failure`); use the Helm 4 names.
- Argo CD renders charts with its own bundled Helm; check which version it bundles when we install it in Phase 5.
